นำความรู้เรื่อง input() มาผสานกับ List ลองคิดและเขียนโค้ดด้วยตนเองก่อน แล้วค่อยกดเปิดดูเฉลยด้านล่างครับ

กิจกรรมที่ 1 • รับค่าข้อความลง List หัวข้อ: input() + .append() + len() + index

โจทย์: ระบบรับรายการสินค้าลงตะกร้า (Shopping Cart)

คำสั่งโจทย์:

สมมุติว่าเรากำลังเขียนระบบให้ร้านค้าออนไลน์ ให้ผู้ใช้ป้อนชื่อสินค้าที่ต้องการสั่งซื้อ จำนวน 3 ชิ้น ผ่านทางคีย์บอร์ด:

1. เริ่มต้นสร้างตัวแปร List ว่าง cart = []

2. ใช้คำสั่ง input() รับชื่อสินค้า 3 ครั้ง แล้วนำเข้าไปต่อท้ายใน List ด้วย .append()

3. ทางร้านมีโปรโมชันพิเศษ! ให้ใช้คำสั่ง .append("ถุงผ้า") เพิ่มของแถมฟรีเข้าไปต่อท้ายตะกร้าโดยอัตโนมัติ

4. แสดงผลลัพธ์ออกทางหน้าจอ:

• รายการสินค้าทั้งหมดในตะกร้า print(cart)
• จำนวนสินค้าทั้งหมดในตะกร้า โดยใช้ฟังก์ชัน len(cart)
• สินค้าชิ้นแรกสุดที่ลูกค้าเลือก (index [0]) และสินค้าชิ้นล่าสุด (index [-1])

💡 วิธีคิดและจุดที่ต้องระวัง:
  • สร้างกล่องว่าง: เริ่มด้วย cart = [] เพื่อเตรียมกล่องไว้ใส่ข้อมูลทีละชิ้น
  • รับข้อความ: ชื่อสินค้าเป็นตัวหนังสือ (str) อยู่แล้ว จึงใช้ input() ได้โดยตรง ไม่ต้องครอบด้วย int()
  • ใส่ของลงกล่อง: เขียนได้ 2 แบบ คือ item = input(...) แล้วตามด้วย cart.append(item) หรือเขียนรวมในบรรทัดเดียวเป็น cart.append(input("..."))
  • ตำแหน่งแรกและท้าย: ตัวแรกคือช่อง cart[0] ส่วนตัวท้ายสุดใช้เลขติดลบ cart[-1] ได้เสมอ สะดวกมาก!

# 1. สร้างตะกร้าเปล่ารอไว้
cart = []

# 2. รับชื่อสินค้า 3 ชิ้นจากผู้ใช้ แล้วทยอยใส่ลงตะกร้า
item1 = input("ใส่สินค้าชิ้นที่ 1: ")
cart.append(item1)

item2 = input("ใส่สินค้าชิ้นที่ 2: ")
cart.append(item2)

item3 = input("ใส่สินค้าชิ้นที่ 3: ")
cart.append(item3)

# 3. แถมของพิเศษฟรีต่อท้ายตะกร้า
cart.append("ถุงผ้า")

# 4. แสดงผลลัพธ์
print("--- สรุปตะกร้าสินค้า ---")
print(f"สินค้าทั้งหมด: {cart}")
print(f"จำนวนของในตะกร้า: {len(cart)} ชิ้น")
print(f"ชิ้นแรกที่เลือก: {cart[0]}")
print(f"ชิ้นสุดท้าย (ของแถม): {cart[-1]}")
คำอธิบายทีละขั้นตอน:
• บรรทัดที่ 2: สร้าง cart = [] เป็น List เปล่า
• บรรทัดที่ 5-12: แต่ละรอบรับค่าจาก input() แล้วใช้ cart.append(...) ยัดของเข้าท้ายตะกร้าทีละตัว
• บรรทัดที่ 15: ใช้ cart.append("ถุงผ้า") เพื่อเพิ่มของแถมลงท้ายตะกร้าอัตโนมัติ ทำให้ตอนนี้ใน List มีของทั้งหมด 4 ชิ้น
• บรรทัดที่ 20-22: ดึงข้อมูลออกมาโชว์ โดย len(cart) จะได้เลข 4, cart[0] คือชิ้นแรก และ cart[-1] คือถุงผ้า

โจทย์: ระบบบันทึกคะแนนสอบและตัดเกรด (Score Tracker)

คำสั่งโจทย์:

คุณครูต้องการให้โปรแกรมรับ คะแนนสอบเก็บคะแนน 3 ครั้ง ของนักเรียน (คะแนนเต็ม 100 คะแนนต่อครั้ง):

1. รับคะแนนสอบ 3 ครั้ง โดยต้องแปลงข้อมูลเป็นตัวเลขจำนวนเต็มด้วย int(input())

2. นำคะแนนทั้ง 3 ค่าเก็บลงใน List ชื่อ scores

3. คำนวณหา:

• คะแนนรวมทั้งหมด โดยใช้คำสั่ง sum(scores)
• คะแนนเฉลี่ย โดยเอาผลรวมหารด้วยจำนวนครั้ง sum(scores) / len(scores)
• คะแนนที่ทำได้สูงสุด max(scores) และต่ำสุด min(scores)

4. ตรวจสอบเงื่อนไขผ่านเกณฑ์:

• ถ้าคะแนนเฉลี่ย ตั้งแต่ 50 คะแนนขึ้นไป (≥ 50) ให้พิมพ์: "ผลการเรียน: ผ่านเกณฑ์ ยินดีด้วยครับ! 🎉"
• ถ้าคะแนนเฉลี่ย น้อยกว่า 50 คะแนน ให้พิมพ์: "ผลการเรียน: ไม่ผ่านเกณฑ์ พยายามใหม่อีกนิดนะ ✌️"

💡 วิธีคิดและจุดที่ต้องระวัง:
  • ต้องครอบ int() เสมอ: ถ้าไม่ครอบ int(input()) คอมพิวเตอร์จะมองคะแนนเป็นข้อความ เช่น "80" ซึ่งจะเอาไปบวกกันไม่ได้!
  • ฟังก์ชันวิเศษของ Python: Python มีคำสั่งสำเร็จรูปสำหรับ List ตัวเลขให้ใช้ได้เลย ได้แก่ sum() (หาผลรวม), max() (หาค่ามากสุด), และ min() (หาค่าน้อยสุด)
  • คำนวณค่าเฉลี่ย: ค่าเฉลี่ย = ผลรวม ÷ จำนวนชิ้น นั่นคือ sum(scores) / len(scores)

score_tracker.py 
# 1. รับคะแนนสอบ 3 ครั้ง แปลงเป็นตัวเลขจำนวนเต็ม
s1 = int(input("กรอกคะแนนครั้งที่ 1: "))
s2 = int(input("กรอกคะแนนครั้งที่ 2: "))
s3 = int(input("กรอกคะแนนครั้งที่ 3: "))

# 2. นำคะแนนทั้งหมดมารวบรวมไว้ใน List
scores = [s1, s2, s3]

# 3. คำนวณค่าสถิติต่างๆ
total = sum(scores)
count = len(scores)
average = total / count

print("--- ผลสรุปคะแนนสอบ ---")
print(f"คะแนนทั้งหมด: {scores}")
print(f"คะแนนรวม: {total} คะแนน")
print(f"คะแนนเฉลี่ย: {average:.2f} คะแนน")
print(f"คะแนนสูงสุด: {max(scores)} | ต่ำสุด: {min(scores)}")

# 4. เช็คเงื่อนไขผ่านเกณฑ์
if average >= 50:
    print("ผลการเรียน: ผ่านเกณฑ์ ยินดีด้วยครับ! 🎉")
else:
    print("ผลการเรียน: ไม่ผ่านเกณฑ์ พยายามใหม่อีกนิดนะ ✌️")
คำอธิบายทีละขั้นตอน:
• บรรทัดที่ 2-4: ใช้ int(input(...)) รับค่าและแปลงเป็นตัวเลขเพื่อนำไปคำนวณคณิตศาสตร์ได้
• บรรทัดที่ 7: รวมคะแนนทั้งหมดเป็น List ด้วยวิธีตรงไปตรงมา scores = [s1, s2, s3]
• บรรทัดที่ 10-12: ใช้ sum(scores) หาผลรวม และหารด้วย len(scores) (คือ 3) ได้ค่าเฉลี่ย
• บรรทัดที่ 17: ใช้ {average:.2f} เพื่อปัดเศษทศนิยมให้แสดงเพียง 2 ตำแหน่งอย่างสวยงาม
• บรรทัดที่ 21-24: ใช้ if average >= 50: เพื่อเลือกว่าจะแจ้งว่าผ่านหรือสอบตก

3. สรุปคำสั่ง For Loop & ฟังก์ชันเด็ดสำหรับ List

ตารางสรุปคำสั่งที่ใช้บ่อยที่สุดในการทำงานจริง พร้อมตัวอย่างโค้ดและหน้าที่

คำสั่ง / รูปแบบ หน้าที่การทำงาน ตัวอย่างโค้ด ผลลัพธ์
for x in list: วนอ่านสมาชิกใน List ทีละตัวตั้งแต่ตัวแรกจนถึงตัวสุดท้าย for name in users: ได้ name ทีละคน
for i in range(n): วนทำงานซ้ำเป็นจำนวน n รอบ (เช่น รับค่า 5 ครั้ง) for i in range(3): ทำซ้ำ 3 รอบ (i=0,1,2)
item in list ตรวจสอบว่ามีของนี้อยู่ใน List หรือไม่ (ให้ค่า True / False) "apple" in cart ได้ True ถ้ามี
sum() หาผลรวมตัวเลขทั้งหมดใน List sum([10, 20, 30]) ได้ 60
max() / min() หาค่าที่มากที่สุด และน้อยที่สุดใน List max(scores) ได้คะแนนสูงสุด
.sort() จัดเรียงข้อมูลใน List จากน้อยไปหามาก (หรือ ก-ฮ) scores.sort() ข้อมูลถูกเรียงลำดับ

4. แบบฝึกหัดท้ายคาบ: แคชเชียร์ซูเปอร์มาร์เก็ต (Supermarket Lab)

เปิดโปรแกรมเขียนโค้ดจริง แล้วพิชิต 5 ด่านประจำสัปดาห์ (คลิกเพื่อติ๊กถูกเมื่อทำแต่ละด่านเสร็จ)

ภารกิจประจำสัปดาห์ที่ 4 5 ขั้นตอน

ภารกิจระบบแคชเชียร์คิดเงินซูเปอร์มาร์เก็ต

✓
ด่านที่ 1: สร้าง List ราคาสินค้าในตะกร้า
สร้างตัวแปร List ชื่อ prices = [45, 120, 80, 25, 200] บรรจุราคาสินค้า 5 ชิ้น
✓

เขียน For Loop วนอ่านค่า price ใน prices แล้วพิมพ์ข้อความว่า "สินค้าราคา: ... บาท" ออกมาทีละบรรทัด
✓
ด่านที่ 3: คำนวณยอดเงินรวมทั้งหมด
ใช้คำสั่ง sum(prices) เพื่อหายอดเงินรวมทั้งหมดที่ลูกค้าต้องจ่าย แล้วพิมพ์ออกมาทางหน้าจอ
✓
ด่านที่ 4: หาสินค้าที่แพงที่สุดและถูกที่สุด
ใช้ฟังก์ชัน max(prices) และ min(prices) เพื่อหาสินค้าชิ้นที่แพงสุดและถูกสุดในบิลนี้
✓
ด่านที่ 5 (โบนัส): ตรวจสอบหาสินค้าพรีเมียม (ราคาเกิน 100 บาท)
ใช้ For Loop ร่วมกับ if price > 100: เพื่อนับดูว่ามีสินค้ากี่ชิ้นที่ราคาเกิน 100 บาท
supermarket_solution.py 
# ด่านที่ 1: สร้าง List ราคาสินค้า 5 ชิ้น
prices = [45, 120, 80, 25, 200]

# ด่านที่ 2: วนพิมพ์ราคาสินค้าแต่ละชิ้นด้วย For Loop
print("--- รายการสินค้าในบิล ---")
for p in prices:
    print(f"สินค้าราคา: {p} บาท")

# ด่านที่ 3: รวมเงินทั้งหมด
total = sum(prices)
print(f"\nยอดรวมทั้งหมด: {total} บาท")

# ด่านที่ 4: สินค้าแพงสุด และ ถูกสุด
print(f"แพงที่สุดในบิล: {max(prices)} บาท")
print(f"ถูกที่สุดในบิล: {min(prices)} บาท")

# ด่านที่ 5 (โบนัส): นับสินค้าที่ราคาเกิน 100 บาท
expensive_count = 0
for p in prices:
    if p > 100:
        expensive_count = expensive_count + 1

print(f"จำนวนสินค้าพรีเมียม (ราคาเกิน 100 บาท): {expensive_count} ชิ้น")
ข้อคิดสำคัญของด่านที่ 5:
เราสร้างตัวแปรตัวนับ expensive_count = 0 ไว้ก่อนเริ่มลูป จากนั้นเมื่อ For Loop วนไปเจอสินค้าตัวไหนที่เข้าเงื่อนไข p > 100 เราก็เพิ่มค่าขึ้นทีละ 1 ด้วย expensive_count = expensive_count + 1 (หรือเขียนย่อว่า += 1) นี่คือเทคนิคพื้นฐานที่ใช้บ่อยมากๆ ในการเขียนโปรแกรมจริงครับ!
